# tracks. – website

Static page that explains tracks., a live instrument for electronic music. Plain HTML and screenshots,
no build step and nothing loaded from other servers. Served by GitHub Pages from `main`.

Screenshots come from the app's snapshot mode (`tracks --snapshot <file> --tab <tab> --size 1512x982`),
scaled to 1800 px wide JPEG. The looping videos in `video/` come from its video mode
(`--video <dir> --scene site-session|site-fx|site-drums`).
